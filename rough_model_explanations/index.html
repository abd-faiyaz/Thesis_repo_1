Recommended starting points

  • Broadcast + MLDP hybrid — low cost, strong manifest balance
  • ANASTASIA behavioral (lite) — bytecode behavior, 128-d MLP

All 11 models

  1. Broadcast receiver + permission classifier — Mohsen et al. 2017
  2. MLDP-pruned permission classifier — Permission Extraction Framework 2020
  3. Broadcast + MLDP permission hybrid — cross-paper manifest fusion
  4. ANASTASIA behavioral classifier (lite) — Fereidooni et al. 2016
  5. LinRegDroid permission classifier — minimal linear baseline
  6. FexDroid category-pruned sparse classifier — ICCAI 2018
  7. ERBE permission + intent MLP — manifest MLP ~1K-d
  8. Dex header + broadcast receiver fusion — MSFDroid H + Mohsen receivers
  9. ANASTASIA + manifest BoW fusion — 128-d behavioral + 4381-d BoW, ASCNN Pattern A, concat 4509-d
  10. FexDroid + raw APK tail dual-branch — 3K–5K sparse + 1DCNN last 1024 bytes, late fusion, 95–97% tail accuracy
  11. MLDP + Dex header cascade — ~30-d MLDP + 104-d header, fused MLP 150-d or multistep cascade
