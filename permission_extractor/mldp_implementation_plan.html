MLDP-Pruned Permission Classifier — Implementation Plan

Paper: IJACSA 2020 — Permission Extraction Framework for Android Malware Detection (MLDP)
Aligned with Pipeline_full_concept.html (P0–P8 + A1–A4)
Proposed model_id: mldp_pruned_permission · domain: manifest_permissions_mldp · On-device: yes (~20–40 dims + linear/tiny MLP)

Scope & role in thesis

Unlike LinRegDroid (full permission vocabulary + linear regression), this model applies Multi-Level Data Pruning (MLDP) offline on the training corpus: PRNR ranking → support filter → association-rule mining, yielding a frozen permission set \(\mathcal{S}\) with \(|\mathcal{S}| \approx 20\)–40. Inference uses only \(\mathbf{x} \in \{0,1\}^{|\mathcal{S}|}\), then a linear SVM (paper) or tiny MLP (ONNX-friendly) outputs malware_probability.

Self-contained project under permission_extractor/. Thesis comparison axis: LinRegDroid (full ~135–400-d, MLR) vs MLDP (pruned ~20–40-d, SVM/MLP) vs VigiDroid XGBoost (~2500-d).

Critical leakage rule: PRNR counts, support thresholds, and association rules must be computed from the train split only. Val, dev_test, and temporal_holdout only receive encoding with the frozen \(\mathcal{S}\).

P1 — Dataset indexing

Exit criteria artifacts/dataset_index.csv + split list files.

Split policy (match LinRegDroid unless Q1 says otherwise)

  • train / val / dev_test: stratified 70/15/15 from 2020+2021 APKs
  • temporal_holdout: all 2022+2023 APKs (evaluate later, not used in MLDP fitting)

Script: src/preprocessing/scan_dataset.py

  1. Walk apk_root/{year}/{benign|malware}/*.apk; SHA-256 dedup.
  2. Labels from parent folder: 0=benign, 1=malware.
  3. Write dataset_index.csv columns: apk_id, path, label, year, split.
  4. Write artifacts/splits/{train,val,dev_test,temporal_holdout}.txt.

P2 — Feature extraction & MLDP pruning

Exit criteria Frozen selected_permissions.json, pruned shards for all splits, failed_apks.log.

P2a — Full permission transactions (all splits)

Script: build_transactions.py

  1. Parse each APK manifest via pyaxmlparser; normalize tokens (VigiDroid).
  2. Store per APK: transactions/{split}/{apk_id}.json → list of permission strings.
  3. Also build full_permission_vocab.json from train transactions only (for ablation baseline).

P2b — MLDP selection (train split ONLY)

Script: run_mldp_selection.py → src/mldp/pipeline.py

Stage 1 — PRNR

\[ \text{PRNR}_j = \frac{M_j / N_m}{B_j / N_b + \epsilon} \]

  1. Count \(M_j, B_j\) per permission on train APKs.
  2. Drop near-equal rates: \(|\rho_j^M - \rho_j^B| < \delta\).
  3. Sort by PRNR descending; keep top-K (default 80) → prnr_scores.json.

Stage 2 — Support filter

\[ \text{supp}(j) = \frac{|\{i : j \in \text{APK}_i\}|}{N_{\text{train}}} \]

  1. Keep permissions with \(\text{supp}(j) \geq \theta_{\min}\) (default 0.01).
  2. Optionally drop \(\text{supp}(j) > \theta_{\max}\) (too ubiquitous).
  3. Write support_stats.json.

Stage 3 — Association rules

  1. Build transactions from malware train APKs using Stage-2 candidates.
  2. Run FP-Growth (mlxtend) with min support σ.
  3. Keep rules with confidence ≥ θ_conf and lift ≥ threshold.
  4. Union all permissions in retained rules → final set \(\mathcal{S}\).
  5. If \(|\mathcal{S}|\) is too small, fallback: top PRNR permissions after support filter until min size (document in JSON).
  6. Write selected_permissions.json: { "permissions": [...], "S": 30, "mldp_version": 1 }.

P2c — Pruned vector shards

Script: extract_pruned_vectors.py

  1. Load frozen \(\mathcal{S}\); for each APK build \(\mathbf{x} \in \{0,1\}^{|\mathcal{S}|}\).
  2. Write processed/shards/{split}/{apk_id}.npz with keys x, label.
  3. Write manifest_{split}.json for DataLoader.
Do not re-run MLDP on val/test/holdout — only encode with frozen \(\mathcal{S}\).

P4 — Model definition

Exit criteria Forward pass: x → malware_probability.

Option A — Linear SVM (paper-default)

sklearn.svm.LinearSVC with probability=False at train time; calibrate with CalibratedClassifierCV on val if needed, or use Platt-style sigmoid on decision function for ONNX.

Decision: \(\hat{y} = \sigma(\mathbf{w}^T \mathbf{x} + b)\) for export consistency.

Option B — Tiny MLP (mobile ONNX)

Linear(|S|, 32) → ReLU → Linear(32, 1) → Sigmoid

Train with BCEWithLogitsLoss; ~few KB weights. Easier ONNX parity than native SVM export.

PyTorch export wrapper

Regardless of sklearn/PyTorch train path, P7 copies trained weights into a fixed nn.Sequential for ONNX.

P5 — Training

Exit criteria artifacts/checkpoints/mldp_pruned.pth + sklearn joblib if applicable.

  1. Load train shards → \(\mathbf{X}_{\text{train}}, \mathbf{y}\).
  2. Fit classifier (SVM or tiny MLP) on pruned vectors only.
  3. Save checkpoint, hyperparams, and \(|\mathcal{S}|\) in training_meta.json.
  4. Log top weighted permissions (SVM coef magnitudes) for thesis interpretability.

Optional P5b: Grid-search MLDP thresholds on val only (re-run P2b+P5 inner loop); never touch dev_test or temporal_holdout for tuning.
