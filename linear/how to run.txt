Dataset: Hugging Face android-apks bucket (~13.5k APKs, year folders 2020–2023).
Default corpus: /mnt/Files/thesis_full_dataset (see config/default.yaml paths.apk_root)

cd linear
source scripts/activate_thesis_env.sh   # repo-root thesis_venv
python scripts/verify_setup.py          # P0 — must pass before full run

Full pipeline (P0–P8):
./run_linregdroid.sh

Smoke / dev run (subset of APKs; not thesis numbers):
PREPROCESS_LIMIT=500 ./run_linregdroid.sh

P6 eval (default): val (threshold tuning) + temporal_holdout (primary test → test_results.json)
Optional dev_test (in-distribution check only):
python -m src.training.evaluate --splits val dev_test temporal_holdout

Split policy (thesis):
  stratified_development — train/val/dev_test from 2020+2021 (stratified by label)
  temporal_holdout — primary test on 2022+2023 (reported as split=test in test_results.json)
  Documented in config/default.yaml pipeline.split_policy_note

Deployed model variant (VigiDroid + thesis):
  Single sklearn MLR (no bagging ensemble)
  Decision rule: LinRegDroid1 — malware if clamp(linear_score,0,1) >= 0.5
  (LinRegDroid2 nearest-class reported offline when evaluation.report_both_variants: true)
  See Android_Works/momo_deployed_variants.md
